ISKRA EXCHANGE — CINEMATIC HOMEPAGE BUILD

Files:
- index.html: replacement homepage
- cinema.css: homepage-specific visual system and responsive styling

Integration:
1. Keep the existing style.css and all existing secondary pages.
2. Upload index.html to the repository root, replacing the current homepage.
3. Upload cinema.css to the repository root as a new file.
4. The new homepage continues to link to services.html, about.html, contact.html, and policies.html.

The homepage uses Three.js from jsDelivr for its procedural 3D environment. If WebGL is unavailable, the CSS atmospheric background remains as a visual fallback. Reduced-motion preferences disable the 3D animation.
