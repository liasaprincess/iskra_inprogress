# Iskra Exchange landing page

## Preview locally
1. Extract this ZIP.
2. Keep `index.html`, `styles.css`, `script.js`, and the `assets` folder together.
3. Open `index.html` in a browser. For best results, use a small local server or VS Code Live Server.

## Customize
- Replace `assets/divinebydesign.png` to change the hero image.
- Edit `index.html` to change copy, service cards, and navigation.
- Edit `styles.css` to change colors, spacing, glass effects, or typography.
- Fonts are loaded from Google Fonts (DM Sans and Playfair Display), so an internet connection is needed for those fonts. System fallbacks are included.

The contact button currently opens an email to `hello@iskraexchange.cc`; change that address in `index.html` if needed.
